# Focus Timer

A simple Pomodoro timer for study sessions, built as my Week 1 vibe-coded app.

**Live app:** https://batu_bat.github.io/focus-timer/

## Features
- Focus (25 min), short break (5 min) and long break (15 min) modes
- Start / pause / reset, with a progress bar and a sound when time is up
- Counts how many focus sessions you finished today
- Small task list ("What are you working on?")
- Saves tasks and today's count in the browser (localStorage)
- Works on phone and desktop, supports dark mode

## Tech
Plain HTML, CSS and JavaScript in a single `index.html` file. No build step.
Hosted with GitHub Pages.

## How to run locally
Download `index.html` and open it in any browser.
